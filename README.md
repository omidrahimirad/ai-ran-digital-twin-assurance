# AI-Assisted RAN Digital Twin for Closed-Loop Network Assurance

Simulation-based, vendor-neutral engineering prototype for deterministic synthetic RAN telemetry, hybrid anomaly detection, explainable diagnosis, lightweight digital-twin prediction, and shadow-mode safety validation.

> This project uses synthetic data. It is a 6G-aligned, IMT-2030-inspired prototype—not a standards-compliant, production-ready, or live-network system.

The full implementation and reproducible results are developed on `feat/initial-mvp`.
